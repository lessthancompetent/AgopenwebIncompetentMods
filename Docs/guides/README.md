# AgOpenWeb user guides

Plain-language guides for things AgOpenWeb does beyond stock AgOpenGPS.
Written for the person in the tractor seat, not for programmers.

| Guide | What it covers |
|---|---|
| [Connecting your modules](module-connections.md) | Getting steer, machine and rate boards talking to AgOpenWeb — Ethernet, WiFi or USB — and what to check when a module won't show up |
| [The work switch](work-switch.md) | Maintained switch vs momentary button, wiring polarity, what the switch actually turns on and off, and how to bench-test it |
| [Headland styles](headland-styles.md) | The Route Planner's Headland tab: Classic laps, Spiral in, Spiral out, None — and which one suits which job |
| [Route Planner basics](route-planner-basics.md) | A short tour of the Route Planner: patterns, split lines, planning, steering the plan, and the ETA |
| [Terrain](terrain-map.md) | The field elevation map: recorded automatically while you drive, shown with the Terrain toggle, and what altitude accuracy to expect |

All screenshots of button and tab names in these guides match the app as built.
If a name here doesn't match your screen, you are probably on an older version.
